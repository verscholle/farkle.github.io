# Punktezähler auf dem iPhone installieren

Die App ist eine installierbare Web-App (PWA). Sie benötigt keine App-Store-Freigabe.

## Veröffentlichen

Den gesamten Ordner `punktezaehler` auf einen HTTPS-Webspace hochladen, zum Beispiel GitHub Pages, Netlify Drop oder einen eigenen Webserver. Für die Installation und Offline-Funktion ist HTTPS erforderlich.

## Auf dem iPhone installieren

1. Die veröffentlichte Adresse in **Safari** öffnen.
2. Auf **Teilen** tippen.
3. **Zum Home-Bildschirm** wählen.
4. Mit **Hinzufügen** bestätigen.

Danach startet der Punktezähler wie eine normale App im Vollbild. Namen, Punktestände und die letzten Eingaben werden ausschließlich lokal auf dem Gerät gespeichert.
